# Three turnkey desk versions

All three share the same law: **signals may be automatic. Money may not.**

No version below stores a seed phrase, signs a Phantom transaction unattended, or places a live Coinbase/Kraken order from this website.

## Version A — Signal Concierge (ship first · still running)

Flow ends with version key (`/gate.html` KEEP VERSION A), Sunday dark (`/sunday.html` SUNDAY STAYS DARK), evening walk (`/walk.html` WALK TO NIGHT), then Daily Close (`/close.html` CLOSE THE DESK) and `/night.html`.

Why it wins: one integration, visible gate, you already know the logic.
Do not build yet: exchange execution, smart-order routing.

## Version B — Multi-venue Paper Desk
Same tickets as A, plus read-only adapters. Live keys never on this site. Watch addresses only. Never request a signature from a bot.

Ten Grok roles: Ingestor, Regime, Risk veto, Sizer, Scribe, Devil’s advocate, Compliance tone, Mangasm sales liaison (never trades), Night watch, Post-trade journal. All ten may speak. Only the human key releases.

## Version C — Dual-confirm Hopper
Script flag + Grok risk bot does not veto + human approve (PAPER ONLY on this build). Missing any one kills the ticket.
